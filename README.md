# STT-DB Modulararbeit II

Datenbankimplementierung für Swiss Table Tennis mit Microsoft SQL Server auf einer Linux-Vagrant-VM.

## Technologien

- Windows 11
- Vagrant
- Linux
- Microsoft SQL Server
- SQL Server Management Studio
- Git und GitHub

## Projektbereiche

- Verbände und Clubs
- Spieler und Vereinszugehörigkeiten
- Elo und Klassierungen
- Ligawettbewerbe und Mannschaften
- Begegnungen, Einzel, Doppel und Sätze
- Turniere und Anmeldungen
- Views, Funktionen und Stored Procedures
