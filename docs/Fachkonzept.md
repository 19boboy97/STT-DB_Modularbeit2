# Fachkonzept

## Projekt

Entwicklung einer Microsoft-SQL-Server-Datenbank für Swiss Table Tennis.

## Ziel

Die Datenbank bildet unter anderem folgende Bereiche ab:

- Verbände und Clubs
- Spieler und Vereinszugehörigkeiten
- Saisons und Alterskategorien
- Elo-Werte und Klassierungen
- Ligawettbewerbe und Mannschaften
- Begegnungen mit Einzel-, Doppel- und Satzresultaten
- Turniere und Anmeldungen

## Technische Umgebung

- Windows 11 als Client
- Vagrant
- Linux-VM
- Microsoft SQL Server
- SQL Server Management Studio
- Git und GitHub
