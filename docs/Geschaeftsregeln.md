# Geschäftsregeln

## Spieler

- Die Lizenznummer ist lebenslang eindeutig.
- Es wird nur der aktuelle Spielername gespeichert.
- Die Alterskategorie bleibt während einer Saison unverändert.
- Spieler können einen Hauptverein und eine Mehrfachlizenz besitzen.

## Klassierungen

- Jeder Spieler besitzt eine Herrenklassierung.
- Frauen besitzen zusätzlich eine Damenklassierung.
- Beide Klassierungen basieren auf demselben Elo-Wert.
- Die Turnierbewertung erfolgt zu Saisonbeginn und Saisonmitte.

## Begegnungen

- Das Standardspielsystem besteht aus neun Einzeln und einem Doppel.
- Treten nur zwei Spieler einer Mannschaft an, werden drei Einzel forfait verloren.
- Das Doppel kann von den beiden anwesenden Spielern gespielt werden.
- Forfaitspiele verändern den Elo-Wert nicht.
- Aufgaben nach Spielbeginn sind Elo-relevant.

## Mannschaftspunkte

- 8 bis 10 Siege: 4 Punkte
- 6 bis 7 Siege: 3 Punkte
- 5 Siege: 2 Punkte
- 3 bis 4 Siege: 1 Punkt
- 0 bis 2 Siege: 0 Punkte
